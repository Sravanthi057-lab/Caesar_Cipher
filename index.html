How it works

Each letter is shifted a fixed number of places (the key k) along the alphabet, wrapping from Z back to A. Letters are numbered A=0 … Z=25. Uppercase and lowercase are kept; spaces, numbers and punctuation stay the same.

Example (k = 3): HELLO → KHOOR

Formulas

Encryption: E(x) = (x + k) mod 26

Decryption: D(x) = (x − k + 26) mod 26

x = letter position (0–25), k = shift key.

Limitations

  • Only 25 useful keys — brute force tries all of them in seconds.
  • Letter frequencies are preserved, so frequency analysis breaks it.
  • Each letter always maps to the same letter (monoalphabetic).
  • For learning only — never use it to protect real data.
